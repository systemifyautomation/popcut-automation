# Popcut AI Matchmaker - Installation Guide

## For Lizz: How to Install the Chrome Extension

Hi Lizz! This guide will walk you through installing the Popcut AI Matchmaker extension in Chrome. Don't worry - it's easier than it looks!

---

## Step 1: Download and Extract the Files

1. **Download the ZIP file** I sent you on Slack
2. **Right-click** the ZIP file and select **"Extract All..."**
3. Choose a location you'll remember (like your Documents folder)
4. Click **"Extract"**

You should now have a folder called `popcut-automation` with all the extension files inside.

---

## Step 2: Open Chrome Extensions Page

1. **Open Google Chrome**
2. **Click the three dots** (⋮) in the top-right corner of Chrome
3. Go to **Extensions** → **Manage Extensions**
   
   *OR simply type this in your address bar:* `chrome://extensions`

---

## Step 3: Enable Developer Mode

1. On the Extensions page, look for the **"Developer mode"** toggle in the **top-right corner**
2. **Click the toggle** to turn it ON (it should turn blue)

---

## Step 4: Load the Extension

1. Click the **"Load unpacked"** button (it appears after you enable Developer mode)
2. **Browse to the folder** where you extracted the files
3. Select the **`popcut-automation`** folder
4. Click **"Select Folder"**

✅ **Done!** The extension is now installed!

---

## Step 5: Pin the Extension (Optional but Recommended)

1. Click the **puzzle piece icon** (🧩) in Chrome's toolbar (top-right)
2. Find **"Popcut AI Matchmaker"** in the list
3. Click the **pin icon** next to it

This makes the extension easily accessible from your toolbar.

---

## How to Use the Extension

### On a Fathom Video Page:

1. **Go to any Fathom video** (fathom.video/share/...)
2. **Click the Popcut AI Matchmaker icon** in your Chrome toolbar
3. The extension will **automatically extract** the Fathom ID and video information
4. **Click "Start AI Matching"**
5. **You can close the popup** - the extension will continue working in the background!
6. When results are ready, the extension will either:
   - Automatically re-open to show results
   - Show a badge notification - just click the icon to see results

### Manual Entry:

1. **Click the extension icon** anywhere
2. **Enter a Fathom video ID** manually
3. **Click "Start AI Matching"**
4. Wait for results (or close and come back later!)

---

## Troubleshooting

### Extension not showing up?
- Make sure Developer mode is ON
- Try refreshing the Extensions page (chrome://extensions)
- Make sure you selected the correct folder (the one with manifest.json inside)

### "Load unpacked" button is gray?
- Developer mode might not be enabled - toggle it on in the top-right

### Extension shows an error?
- Make sure the config.js file is present in the folder
- Check that all files were extracted from the ZIP
